# Ranger reference

**Ranger** ([ranger-k8s](https://charmhub.io/ranger-k8s)) is a Kubernetes operator for [Apache Ranger](https://ranger.apache.org/), which provides the Canonical Data Mesh with fine-grained access policies and an audit trail for the query layer.
