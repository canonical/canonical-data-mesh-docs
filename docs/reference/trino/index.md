# Trino reference

**Trino** ([trino-k8s](https://charmhub.io/trino-k8s)) is a Kubernetes operator for [Trino](https://trino.io/), the distributed SQL query engine that gives the Canonical Data Mesh a single federated access layer over every connected data source.
