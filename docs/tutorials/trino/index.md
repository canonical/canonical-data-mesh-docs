# Get started with Trino

```{note}
This page is a placeholder; the tutorial is planned but not yet written.
```

[Trino](https://trino.io/) is a distributed SQL query engine that queries data where it lives. This tutorial will describe how to get started with Charmed Trino, the Kubernetes operator that deploys and manages it.

Planned outline:

1. Set up the environment (MicroK8s and Juju).
2. Deploy the Trino coordinator and workers.
3. Connect a PostgreSQL database as a catalog.
4. Run a first federated query.
5. Clean up.

In the meantime, see the [trino-k8s Charmhub page](https://charmhub.io/trino-k8s) and the {ref}`Superset Trino integration guide <how-to-superset-integrate-with-trino>`.
